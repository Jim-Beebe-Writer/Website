# Change Plans in Vantage Membership System

## Prerequisites

This guide uses two VMS windows. You must know how to switch between open windows in Windows.

## Context

Members can ask to change plans under set rules. See *Processing Plan Change Guideline On or Off Marketplace* for details on when changes are allowed.

**Important (Customer Advocates):** Don't use these steps.

* If an off-Exchange member calls to change a plan, tell them to apply via the Retail Shopping Cart (RSC).

* If they want a paper form, direct them to their state site (www.bcbsxx.com) to download one.

* If they insist you send a form, create a Dashboard Service Request (SR) task for ICSS (queue UHUENRO).

**Important (Processors):** Don't use these steps for Texas plans. Reroute Texas requests to queue U312344.

Use this guide for plans in IL, MT, NM, or OK.

## Steps

### Setup

1. In the VMS menu, select the icon to open a second window. Log into VMS there (**Window Two**).

   * **Note:** The main window is **Window One**.

   * **Important:** Switch windows only when told.

### Find the member

1. Switch to **Window One**.

1. In the VMS menu, select **Profiles > Members**.

1. Type the member ID and select **Do Search**.

1. Select the member ID to open the member tree screen.

### Open the member's coverage tree 

1. Switch to **Window Two**.

1. In the VMS menu, select **Processing > Customer Service**.

1. In **Inquiry Reason**, pick **Plan Change (Downgrade)**.

   * **Note:** Pick this even if coverage goes up.

1. In **Entity ID**, type the member ID.

1. Select **Accept** to see matching members.

1. Under **Matching Members**, select the member ID. The tree view opens.

### Cancel the existing coverage

1. Right-click the coverage to replace.

1. Select **Cancel**. The Member Termination window opens.

1. In **Termination Date**, enter the day before the new start date.

   * **Note:** If retroactive, use the old plan's start date.

1. Select the glass icon next to **Term Reason Code**.

1. In the search box, select **Do Search**.

1. Pick a reason from the list.

1. Select **Return ID**.

1. In the Member Termination box, select **Change & Exit**.

### Find the cancelled policy

1. Switch to **Window One**.

1. Set **Display InActive?** to **Yes**.

1. Select **Do Search**.

1. Right-click the canceled policy and pick **View**.

### Add the new coverage

1. Switch to **Window Two**.

1. Set **Display InActive?** to **Yes**.

1. Select **Do Search**.

1. In the tree, right-click the Line of Business (LOB) to add.

1. Select **Add** to open the Eligibility Coverage Add screen.

### Complete the Eligibility Coverage Add screen

1. In the Eligibility Coverage Add screen, complete these fields:

   * **Effective Date**: Enter the new plan start date.

   * **Product Effective Date**: Set to match Effective Date.

   * **LOB**: Select the target LOB if not filled automatically.

   * **Original Effective Date**: Copy from old plan (check Window One).

   * **Plan Strategy ID**: Enter the new Plan Strategy ID.

      * **Note:** If the new Plan Strategy ID is missing from the SR, see *Plan Strategy ID and Class of Contract Code - Overview*.

   * **Bill Flag**: Copy from old plan (check Window One).

   * **Coverage Code**: Copy from old plan (check Window One).

   * **COBRA Flag**: Keep as **No (N)**.

   * **COBRA A/R Type**: Keep as **Group (G)**.

   * **Manual Enrollment**: Change to **Yes**.

1. Select **Add and Exit**.

1. If a prompt asks to update dependents, keep **Yes** and select **Submit**.

1. Set **Display InActive?** to **Yes** and select **Do Search**.

### Open the Ancillary Coverage Info

1. Switch to **Window One**.

1. In the Eligibility Coverage View box, select **Exit**.

1. Set **Display InActive?** to **Yes**.

1. Select **Do Search**.

1. Right-click the member name.

1. Hover over **Drill Down**.

1. Pick **Ancillary Coverage Info**.

1. Right-click the ended record.

1. Select **View**.

### Start a new ancillary coverage record

1. Switch to **Window Two**.

1. Right-click the member name.

1. Hover over **Drill Down**.

1. Pick **Ancillary Coverage Info**.

1. Right-click **Ancillary Coverage Records**.

1. Select **Add**.

1. Fill out the **Coverage Ancillary Add** screen:

   * **LOB**: Pick the right LOB.

   * **Effective Date**: Enter the start date.

   * **Termination Date**: Type `12/31/9999`.

   * **Case Number**: Enter member ID + date as `ymmdd` (for example `88776655440225`).

   * **Claims Investigation**: Leave blank.

   * **Pre-Existing End Date**: Leave blank.

   * **Application Received Date**: Enter request date.

   * **Application Signature**: Enter request date.

   * **Member Issue Date**: Enter today's date (`mm/dd/yyyy`).

   * **Conversion Switch Date**: Leave blank.

   * **Control Number**: Leave blank.

   * **Application Type**: Pick **New (N)**.

   * **External Business**: Copy from old plan (check Window One).

   * **Source Type**: Copy from old plan (check Window One).

   * **External Ref#**: If External Business is Yes, copy from old plan.

   * **Proxy Sign Ind**: Copy from old plan.

   * **Proxy Sign Date**: If Proxy Sign Ind is Yes, copy from old plan.

   * **Market Type**: Copy from old plan.

   * **Variant Code**: Match to the last 2 digits of the Contract Code:

    | Last Two Digits of Contract Code | Variant Code | 
    | ----- | ----- | 
    | 00 | Non-Exchange variant | 
    | 01 | Exchange variant (no CSR) | 
    | 02 | Open to Native Americans under 300% FPL | 
    | 03 | Open to Native Americans over 300% FPL | 
    | 04 | 73% AV Silver CSR | 
    | 05 | 87% AV Silver CSR | 
    | 06 | 94% AV Silver CSR | 

   * **Class of Contract Code**: Enter the 16-digit code for the new plan.

   * **Other Dental QHP**: Copy from old plan.

   * **QHP Sign Date**: Copy from old plan.

   * **Carrier**: Copy from old plan.

   * **Disability Affecting Communication**: Copy from old plan.

   * **Communication Materials Needed**: Copy from old plan.

   * **Policy Should be Mailed**: Copy from old plan.

1. Select **Add and Exit**.

1. Set **Display InActive?** to **Yes** and select **Do Search**.

### Complete ancillary coverage for dependents

1. Repeat the steps in **Start a new ancillary coverage record** for each dependent on the policy.

### Check for active rate records

1. Right-click the member name.

1. Hover over **Drill Down**.

1. Pick **Ancillary Rate Info**.

1. Check that an active rate record shows.

   * **Note:** If missing, email *Retail Market Operations - Rate Administration* with the ID and LOB.

1. Set **Display InActive?** to **Yes** and select **Do Search**.

1. Repeat the steps in this sub-section for each dependent.

### Update the funding assignment, subsidy, and broker assignment

1. Right-click the member name.

1. Hover over **Drill Down**.

1. Select **All Details**.

1. Fix the funding assignment:

   1. Under **Member Funding Assignments**, find the ended assignment.

   1. Right-click it and pick **Change**.

   1. In **Termination Date**, type `12/31/9999`.

   1. Select **Change & Exit**.

1. Fix the subsidy (if applicable):

   1. Under **Subsidy Maintenance**, find the ended subsidy record. If none, skip to step 63.

   1. Right-click it and pick **Change**.

   1. Set **Subsidy Termination Date** to `12/31/9999`.

   1. Select **Change & Exit**.

1. Fix broker assignments (if applicable):

   1. Under **Broker Assignments**, look for ended brokers. If none, skip to **Request a policy kit**.

   1. Right-click each record and pick **Change**.

   1. Set **Termination Date** to `12/31/9999`.

   1. Select **Change & Exit**.

### Request a policy kit

1. In **Member Search**, select **Close All** (select **No** in the prompt).

1. Request a Policy Kit:

   1. Select the ID card icon in the member row.

   1. Fill out the form as shown below:

| Field | Action | 
| ----- | ----- | 
| Request For | Set to Member | 
| ID# | Member ID | 
| Members | Primary Insured | 
| Group ID | Member Group ID | 
| Type | Plan Change/Initial Kit (4) | 
| \# of Items | Type 1 | 
| Provider Effective Date (HMO) | Pick latest date | 
| Case Number | Select new coverage case number | 
| Address Source | Primary Mailing address | 
| Order For | M-Member Only | 
| Names on Card | M-Member Only | 
| Card Coverage Date | Active coverage start date | 
| If No Address Then Send to | Leave blank | 
| Card Format | Blue Cross Blue Shield | 
| Request fields | Enter name and address if blank | 

   * **Note:** Don't type in the **Message** field.

### Finish the policy kit order

1. Select **Accept & Order**.

1. Close the order box.

### Finish the inquiry

1. Select the left yellow double arrows (`>>`) to open the Inquiry panel.

1. Select **Finish Inquiry**.

1. Pick **Closed on First Contact**.

1. Pick **Send to Subscriber** and check the box next to the member ID.

1. In **Comment**, enter the SR number.

1. Follow the *RMO Workaround Creating Free Form Correspondence in CUI* guide to send a letter.

1. Follow the *RMO Requesting ID Cards in VUI* guide to order cards.

1. If retroactive, inform Claims:

   1. In the SR, create a new task.

   1. In **Comments**, type: `Re-examine claims due to plan change`, the member ID, and start date.

   1. In **Activity Code 1**, type `PLC`.

   1. In **Employee ID**, type `UHUBENP`.

   1. Select **Save**.

1. If retroactive, inform FinOps:

   1. In the SR, create a new task.

   1. In **Comments**, type: `Reinvoice due to plan change`, the member ID, and start date.

   1. In **Activity Code 1**, type `PLC`.

   1. In **Employee ID**, type `UFINOPS`.

   1. Select **Save**.

1. In the SR, mark the plan change task as **Done**.

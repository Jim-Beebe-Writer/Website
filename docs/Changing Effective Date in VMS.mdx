# Change a Policy Start Date in VMS (Move Date Forward)

This guide shows how to move a policy start date to a later date in VMS.

## Prerequisites

* The new date must be the first day of the month.

## Before You Begin

:::caution Important
Customer Advocates must use the *RMO Workaround Pending Member Inquiries for On Off Marketplace* guide instead.
:::

Use these steps to move a start date forward in VMS.

## Steps

1. Open the inquiry panel.  
   In VMS, click **Processing > Customer Service**. Pick **Effective Date change** as the reason and enter the member ID.
1. Update member start dates.  
   * Change the **Eligibility Coverage** (health and dental) start date to the new date. Update Effective Date, Product Effective Date, and Original Effective Date.
   * Change the **Ancillary Coverage Info** start date to the new date.
1. Update related files.  
   * Change the **Broker Assignment** start date.
   * Change active **Funding Assignments** start dates.
   * Change the **Contacts** start date.
   * Update **Subsidy Maintenance** start dates, if present.
1. Request new ID cards for non-HMO members.  
   VMS creates HMO cards on its own after you update the PCP.
1. Close the inquiry and send a letter.  
   Click **Finish Inquiry**, pick **Closed on First Contact**, and follow the *RMO Workaround Creating Free Form Correspondence in CUI* guide.
1. Update provider dates for HMO policies.  
   Use the *RMO Changing a Provider* guide to update the date for each provider.

## Result

The policy start date is now updated across all VMS files and coverage types.
